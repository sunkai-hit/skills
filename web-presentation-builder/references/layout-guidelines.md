# Layout Guidelines

## One-screen rule
The default Web Presentation behaves like a deck: one logical screen per viewport. Avoid requiring vertical scrolling within a screen.

## Safe area
For 1920×1080, start with approximately 96–140px horizontal and 70–100px vertical safe padding, then tune for the visual style.

## Density
Use hierarchy instead of shrinking:
1. remove redundant text;
2. group related information;
3. turn repeated prose into labels, diagrams, or concise cards;
4. only then adjust spacing/size.

## Vertical balance
Common failure modes:
- all content anchored too high;
- title area consumes too much height;
- bottom becomes empty;
- page only fits after scrolling.

Balance title/header, primary content, and footer/meta as one composition.

## Center-and-detail structures
For hub/spoke diagrams:
- keep detail cards close enough to share one visual field;
- use consistent card sizes;
- do not push spokes to page edges merely to create whitespace;
- make connectors short;
- enlarge detail cards before enlarging empty gaps.

## Grids
Prefer simple repeatable grids:
- 2-column for comparison/detail;
- 3-column for value propositions;
- 4-column for compact categories;
- asymmetrical 40/60 or 45/55 for photo + narrative.
