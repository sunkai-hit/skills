# Typography Guidelines

## Default large-display scale
For leadership/project presentations at 1920×1080:
- page title: 42–56px;
- section title: 26–34px;
- card title: 20–26px;
- body: 18–22px;
- support: 16–18px;
- metric: 32–46px.

Critical text below 15px is a QA warning by default.

## Rules
- Do not solve layout problems by repeatedly reducing font size.
- Keep line lengths moderate; long prose blocks are hard to scan on a large screen.
- Use strong title/body contrast.
- Avoid low-contrast gray text on decorative backgrounds.
- Use fewer weights rather than many subtle weight differences.

## Numbers
Metrics should use larger type and a concise label. If the value is illustrative, add a visible “demo/example” marker.
