# Interaction Guidelines

## Presentation navigation
Support at least:
- keyboard next/previous;
- wheel or trackpad navigation when appropriate;
- clickable progress/nav affordance;
- stable hash/deep-link navigation for QA.

## Motion
Use motion to clarify hierarchy, not to delay access to content.

Recommended:
- subtle entrance transitions;
- short hover feedback on interactive cards;
- reduced-motion fallback;
- deterministic or disabled motion during automated screenshots.

## Modals/details
Use modal or expandable detail only when it preserves the main screen's clarity. The main message must remain understandable without opening every detail.
