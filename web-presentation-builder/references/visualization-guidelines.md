# Visualization Guidelines

## Choose structure by communication goal
- Architecture: layered bands, platform stack, capability map.
- Workflow: horizontal stage line, loop, swimlane.
- Roadmap: milestone timeline.
- Hub/detail: compact radial/grouped layout.
- Comparison: aligned columns or matrix.
- Operations: KPI strip + pipeline/status cards.
- Product capability: interface mock + callouts.

## Avoid
- diagrams with connectors crossing unnecessarily;
- tiny labels inside dense graphics;
- ornamental charts with no decision value;
- decorative metrics presented as real operating data;
- repeated card grids with no visual hierarchy.

## Evidence
If a chart is based on user-provided numbers, preserve the numbers. If no data exists, prefer a conceptual diagram rather than inventing a quantitative chart.
