# skills

Personal reusable skills repository.

## Available skills

- [`web-presentation-builder`](./web-presentation-builder/) — A reusable guided workflow for planning, designing, implementing, QA-ing, packaging, and releasing full-screen Web Presentation projects.

## Repository convention

Each skill lives in its own top-level directory and should include a `SKILL.md` plus supporting templates, references, scripts, examples, and release notes as needed.
